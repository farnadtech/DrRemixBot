# ربات تشخیص آهنگ‌های رپ فارسی | Persian Rap Music Finder Bot

<div dir="rtl">

## معرفی پروژه

ربات تشخیص آهنگ‌های رپ فارسی یک ربات تلگرامی هوشمند است که به کاربران امکان می‌دهد با ارسال یک بخش کوتاه از یک آهنگ (به صورت فایل صوتی، ویس یا ویدیو)، نسخه کامل و اصلی آن آهنگ را دریافت کنند. این ربات با استفاده از تکنولوژی پیشرفته اثر انگشت صوتی (Audio Fingerprinting) قادر به تشخیص آهنگ‌ها حتی در حضور نویز، تغییر سرعت، و یا تغییرات کوچک است.

ربات به صورت اختصاصی برای آهنگ‌های رپ فارسی بهینه‌سازی شده است و دارای یک پایگاه داده غنی از اثر انگشت‌های صوتی آهنگ‌های رپ فارسی است که به طور مداوم به‌روزرسانی می‌شود.

## ویژگی‌های اصلی

- **تشخیص سریع و دقیق آهنگ**: با استفاده از الگوریتم‌های پیشرفته تشخیص اثر انگشت صوتی
- **پشتیبانی از انواع فرمت‌ها**: فایل صوتی، ویس و ویدیو
- **رابط کاربری آسان**: منوهای اینلاین و دکمه‌های تعاملی برای استفاده راحت‌تر
- **سیستم اشتراک**: طرح‌های متنوع با قیمت‌های مختلف (ماهانه، سه ماهه، سالانه)
- **سیستم پرداخت امن**: پرداخت کارت به کارت با تأیید دستی ادمین
- **پشتیبانی کاربران**: سیستم ارتباط مستقیم با پشتیبانی از طریق ربات
- **مدیریت حساب کاربری**: مشاهده وضعیت اشتراک و تاریخچه تراکنش‌ها
- **استفاده آزمایشی**: امکان یک بار استفاده رایگان برای آشنایی با سرویس

## تکنولوژی و روش کار

### تکنولوژی‌های استفاده شده

- **زبان برنامه‌نویسی**: Python 3.10+
- **کتابخانه تلگرام**: python-telegram-bot (PTB) نسخه 20+ با پشتیبانی از API تلگرام
- **پردازش صدا**: کتابخانه‌های NumPy، SciPy و FFmpeg برای پردازش سیگنال‌های صوتی
- **تشخیص اثر انگشت صوتی**: الگوریتم‌های اختصاصی مبتنی بر تبدیل فوریه و تحلیل طیفی
- **پایگاه داده**: ساختار پایگاه داده مبتنی بر JSON برای ذخیره‌سازی اطلاعات کاربران و اثر انگشت‌های صوتی

### فرآیند تشخیص آهنگ

ربات از یک فرآیند چند مرحله‌ای برای تشخیص آهنگ‌ها استفاده می‌کند:

1. **استخراج صدا**: جداسازی صدا از فایل دریافتی (حتی اگر ویدیو باشد)
2. **پیش‌پردازش**: نرمال‌سازی، فیلترینگ و آماده‌سازی سیگنال صوتی
3. **استخراج اثر انگشت صوتی**: محاسبه اثر انگشت صوتی با استفاده از تکنیک‌های پیشرفته استخراج ویژگی‌های فرکانسی و زمانی
4. **تطبیق**: مقایسه اثر انگشت استخراج شده با پایگاه داده آهنگ‌ها
5. **رتبه‌بندی نتایج**: رتبه‌بندی نتایج بر اساس میزان تطابق و اطمینان
6. **ارائه نتیجه**: در صورت یافتن تطابق، ارسال نسخه کامل آهنگ به کاربر

الگوریتم تشخیص به گونه‌ای طراحی شده که حتی با نمونه‌های کوتاه (حداقل 10 ثانیه)، در حضور نویز، تغییر سرعت و سایر دستکاری‌ها نیز قادر به تشخیص باشد.

## سیستم اشتراک و پرداخت

ربات دارای یک سیستم اشتراک پویا است که به کاربران امکان انتخاب از میان طرح‌های مختلف را می‌دهد:

- **اشتراک یک ماهه**: دسترسی کامل به مدت 30 روز
- **اشتراک سه ماهه**: دسترسی کامل به مدت 90 روز با تخفیف
- **اشتراک یک ساله**: دسترسی کامل به مدت 365 روز با تخفیف ویژه

### فرآیند پرداخت

1. کاربر طرح اشتراک مورد نظر خود را انتخاب می‌کند
2. روش پرداخت کارت به کارت را انتخاب می‌کند
3. اطلاعات کارت بانکی برای واریز نمایش داده می‌شود
4. کاربر پس از پرداخت، شناسه پیگیری یا 4 رقم آخر کارت خود را ارسال می‌کند
5. درخواست پرداخت برای ادمین ارسال می‌شود
6. ادمین پس از بررسی، پرداخت را تأیید یا رد می‌کند
7. در صورت تأیید، اشتراک کاربر فعال می‌شود و می‌تواند از خدمات ربات استفاده کند

این سیستم برای جلوگیری از تقلب طراحی شده و از امنیت بالایی برخوردار است.

## نحوه نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.10 یا بالاتر
- pip (مدیریت بسته پایتون)
- FFmpeg (برای پردازش فایل‌های صوتی و ویدیویی)
- توکن ربات تلگرام از @BotFather

### نصب

1. ابتدا مخزن را کلون کنید:
```bash
git clone https://github.com/your-username/persian-music-finder-bot.git
cd persian-music-finder-bot
```

2. بسته‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
```

3. فایل محیطی را تنظیم کنید:
```bash
cp env.example .env
```

4. فایل `.env` را با ویرایشگر متن باز کرده و مقادیر مورد نیاز را تنظیم کنید:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_USER_ID=your_telegram_id
PAYMENT_CARD_NUMBER=your_bank_card_number
PAYMENT_CARD_OWNER=your_name
```

5. ساختار دایرکتوری‌ها را ایجاد کنید:
```bash
mkdir -p data/full data/demo data/fingerprints data/temp
```

### اجرا

برای اجرای ربات، دستور زیر را وارد کنید:
```bash
python telegram_bot.py
```

برای اجرای ربات به صورت دائمی در پس‌زمینه:
```bash
nohup python telegram_bot.py &
```

یا با استفاده از سرویس systemd:
```bash
sudo cp telegram-music-bot.service /etc/systemd/system/
sudo systemctl enable telegram-music-bot
sudo systemctl start telegram-music-bot
```

## نحوه استفاده

### برای کاربران

1. ربات را در تلگرام جستجو کنید: `@YourMusicFinderBot`
2. دستور `/start` را برای شروع وارد کنید
3. یک بخش کوتاه (حداقل 10 ثانیه) از آهنگ مورد نظر خود را به صورت فایل صوتی، ویس یا ویدیو ارسال کنید
4. ربات پس از پردازش، نتیجه را به شما نمایش می‌دهد
5. در صورت تشخیص موفق، نسخه کامل آهنگ برای شما ارسال می‌شود
6. پس از استفاده از سهمیه رایگان، برای ادامه استفاده باید اشتراک تهیه کنید

### برای ادمین‌ها

1. مدیریت پرداخت‌ها: تأیید یا رد درخواست‌های پرداخت کارت به کارت
2. پاسخ به پیام‌های پشتیبانی: دریافت و پاسخ به پیام‌های کاربران
3. مشاهده آمار: مشاهده تعداد کاربران، تعداد اشتراک‌ها و سایر آمارها

## پرسش‌های متداول

### سوال: چرا پس از تشخیص اولین آهنگ باید اشتراک بخرم؟
پاسخ: هزینه‌های نگهداری سرور و پایگاه داده آهنگ‌ها بالاست. ما یک بار استفاده رایگان ارائه می‌دهیم تا با کیفیت خدمات آشنا شوید.

### سوال: اگر ربات نتواند آهنگ من را تشخیص دهد، آیا باز هم باید اشتراک بخرم؟
پاسخ: خیر. تنها در صورتی که ربات موفق به تشخیص آهنگ شما شود، نیاز به خرید اشتراک خواهید داشت. اگر ربات نتواند آهنگ را تشخیص دهد، می‌توانید مجدداً تلاش کنید.

### سوال: اگر اشتراک من منقضی شود، داده‌های من از بین می‌رود؟
پاسخ: خیر. پس از اتمام اشتراک، تنها دسترسی شما به قابلیت تشخیص آهنگ محدود می‌شود و می‌توانید با تمدید اشتراک، مجدداً از تمام امکانات استفاده کنید.

### سوال: آیا می‌توانم اشتراک خود را قبل از اتمام تمدید کنم؟
پاسخ: بله. با تمدید اشتراک، مدت زمان جدید به زمان باقی‌مانده اشتراک فعلی شما اضافه می‌شود.

### سوال: چه آهنگ‌هایی در پایگاه داده شما وجود دارد؟
پاسخ: ما تمرکز ویژه‌ای بر آهنگ‌های رپ فارسی داریم و به‌طور مداوم در حال به‌روزرسانی پایگاه داده هستیم. اگر آهنگ مورد نظر شما در پایگاه داده ما نباشد، می‌توانید آن را به ما اطلاع دهید تا اضافه کنیم.
